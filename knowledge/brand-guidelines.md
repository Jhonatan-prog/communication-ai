# Brand and Visual Guidelines
Status: editable project knowledge; do not treat examples as mandatory branding.
- Default to clean, youthful, welcoming and mobile-readable designs.
- Approved visual references take priority over new suggestions.
- Save palette, typography, layout, logos and image references per event.
- Use appropriate spacing, strong hierarchy and contrast in WhatsApp image previews.
- For La Barquereña examples, references include blue/yellow aerial-photography and botanical cream/forest-green styles. Neither is universally mandatory.
- Do not insert institutional branding, MIRA clothing, political logos or religion-related images unless the event request or approved reference requires it.
- When a user says 'only remove this', change nothing else.
- Record asset provenance and Canva design IDs only when confirmed.
