# Workflow — New Event
1. Choose short slug, e.g. la-barquerena-tour.
2. Copy templates/event-brief.md into events/<slug>/brief.md.
3. Fill user-confirmed facts. All missing logistics = TBD; list conflicts.
4. Event Planner writes events/<slug>/plan.md: objectives, agenda, dependencies, responsibilities, checklist, risks.
5. Requested roles create messages, ecard specification, video plan.
6. Quality Reviewer writes qa-report.md and identifies changes.
7. User approves drafts explicitly; publishing requires separate authorization.
8. Use approved versions for later reminders or post-event recaps.
