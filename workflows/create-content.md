# Workflow — Create Content
Input: approved or current confirmed event brief, channel, target audience and user request.
- Inspect previously approved materials and relevant style reference.
- Route to one content agent, unless request is bundled.
- Use template for messages, e-cards or video.
- Include only confirmed claims; mark unknown details TBD.
- Run independent QA and submit DRAFT for approval.
- On revisions, preserve unmentioned content and re-review changed areas.
