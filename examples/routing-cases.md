# Routing Examples
- "Create a WhatsApp reminder": Copywriter -> Quality Reviewer.
- "Change only the e-card date": Visual Designer -> Quality Reviewer; preserve everything else.
- "Create a route visit event": Event Planner -> selected creative roles -> Quality Reviewer.
- "Write a 30-second invitation reel": Video Producer -> Quality Reviewer.
- "Make a campaign pack": Event Planner -> Copywriter + Designer + Producer -> Quality Reviewer.
- "Publish this approved invitation": check explicit authorization, connected supported channel and exact asset version before any action.
